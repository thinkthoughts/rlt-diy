Draft protocol derived from the TI pilot. Technical verification and release approval are distinct obligations.

Statement identity

Pin elaborated types and definition bodies, bind displayed statements to them, and inventory project sources.

Evidence classification

Distinguish universal theorems, identities, finite instances, counterexamples, definitions, superseded and vacuous statements.

Independent certificates

Pin checker revision, goal, certificate, conventions, formula and verdict; review scientific readings separately.

Versioned specifications

Register versions, exact source locators, changes and added premises.

Source rights

Keep unlicensed originals local and check tracked bytes and digests; history removal is a separate owner decision.

Measurement provenance

Distinguish received bytes, canonical packages and deliveries; retain commitments independently, subject to privacy and retention rules.

Definedness

Undefined differs from zero; unresolved attribution is a valid result.

Fail-closed verification

Require dependencies and inventories; test intended failures and positive controls.

Evidence-derived status

Validate status and counts against evidence; distinguish mathematical, software and physical results.

Independent acceptance

Bind reviewer decision and scope to exact artifact identities; pending review cannot pass a release gate. No self-approval.
