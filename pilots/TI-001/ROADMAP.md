# TI pilot roadmap

Attribution is the gate. Viability is the payoff.

| Milestone | Deliverable | Gate |
|---|---|---|
| TI-001 | Audit existing mathematical baseline; formalization companion to April paper | Exact source fidelity; proof coverage and unsupported RLT domains recorded |
| TI-002 | November eleven-field schema, raw record preservation, clock correction, deterministic frames | Validation, explicit missing/carried-forward semantics, provenance and timing uncertainty |
| TI-003 | Synthetic magnetometry test bench | Independent ground truth, reproducible seeds, noise and sensor response models, adversarial cases |
| TI-004 | Magnetic attribution | Rank/null-space conditions, calibration, controlled intervention, conditioning, uncertainty, unresolved outcome |
| TI-005 | Bench and phantom specification | Independent reference measurements, preregistered criteria and stop rules; no human experiments implied |
| TI-006 | Synchronization and viability | April PLV aggregation as candidate, November S(t) left open; independent viability limits and false alarm criteria |
| TI-007 | Physical validation | Qualified collaborators, instrumentation, ethics/consent, evidence; gate before validated viability claims |
| DIY handoff | Author-owned repo, roadmap, prompts, evidence and reproducible setup | Explicit agreement on affiliation, scope, license, funding and domain transfer |

Engineering choices are independent proposals, not author requirements unless sourced. Preserve original eleven fields; add versioned calibration metadata separately. GPS data should be optional in independent bench design and protected in real deployments. Keep synthetic and physical evidence separate. Literature leads: https://doi.org/10.3390/s25154642 and https://doi.org/10.3389/fmedt.2024.1457535; inspect before using numerical parameters.
